# новейший репозиторый с подпространством

## Ответы на вопрос взюхи

1. **Почему папку `venv` не нужно коммитить в Git?**
   Папка весит слишком много (тысячи файлов установленных библиотек) и содержит пути/файлы, привязанные к конкретной ОС и компьютеру.

2. **Что произойдёт, если другой разработчик склонирует репозиторий без папки `venv`? Как ему восстановить окружение?**
   При запуске `main.py` возникнет ошибка `ModuleNotFoundError: No module named 'requests'`. Чтобы восстановить окружение, разработчик должен создать своё локальное окружение (`python -m venv venv`), активировать его и установить зависимости командой `pip install -r requirements.txt`.

3. **Зачем нужен файл `requirements.txt` и как он связан с `.gitignore`?**
   `requirements.txt` — это лёгкий текстовый список установленных пакетов и их версий (`pip freeze > requirements.txt`). В отличие от папки `venv/`, он **не добавляется** в `.gitignore` и обязательно попадает в Git, чтобы любой мог воспроизвести рабочее окружение.
